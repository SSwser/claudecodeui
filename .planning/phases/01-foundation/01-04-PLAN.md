<threat_model>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| route/session selection -> tab model | Explicit navigation and restored tab state compete for ownership of the active session context |
| tab interactions -> pane assignment | Drag/drop and context-menu actions can reassign sessions between panes |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-04-01 | T | src/hooks/useAppTabs.ts | mitigate | Prefer explicit route/session identifiers over stale restored tab state and drop orphaned tab entries during hydration |
| T-01-04-02 | D | src/components/app/view/PaneDropZone.tsx | mitigate | Restrict drag activation to known tab payloads and debounce pane reassignment so accidental edge hover does not thrash layout state |
| T-01-04-03 | E | src/components/app/view/TabContextMenu.tsx | accept | Pane assignment is same-user UI state only; no privilege boundary exists beyond ensuring actions cannot target missing sessions |
</threat_model>
