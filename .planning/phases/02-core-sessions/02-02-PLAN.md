<task type="auto">
  <name>Task 1: Create project and workspace service modules</name>
  <files>server/services/projectService.js, server/services/workspaceService.js</files>
  <action>
  1. Create `server/services/projectService.js`:
  - Import `db` from `../database/db.js`
  - `createProject({ name, directoryPath, multiWorkspaceEnabled })`:
    - Validate `directoryPath` exists on filesystem (use `fs.existsSync`)
    - INSERT into projects table
    - Create default workspace (is_default=1) via workspaceService
    - Trigger async session scan for that directory (D-18)
    - If directory has `.git` and contains worktrees, detect them (D-02/D-28)
    - Return created project with its default workspace
  - `getProjects({ sort, includeDeleted })`:
    - Query projects WHERE is_deleted=0 (unless includeDeleted)
    - Sort options: 'name' (alphabetical), 'recent' (updated_at DESC), 'created' (created_at DESC)
    - Include workspace count and active session count per project
    - Per D-06: return project list for Sidebar display
  - `getProjectById(id)`:
    - Query single project with its workspaces and session counts
  - `softDeleteProject(id)`:
    - UPDATE is_deleted=1 (D-22: no filesystem changes)
    - Broadcast WebSocket 'project_deleted' message
  - `scanProjectSessions(projectId, directoryPath)`:
    - Reuse logic from existing `server/projects.js` scanning (scan ~/.claude/projects/ matching the directory)
    - For each discovered session, INSERT into session_state if not already tracked
    - This runs async after project creation (D-18)
  - `detectWorktrees(directoryPath)`:
    - Run `git worktree list --porcelain` in the directory
    - Parse output to find existing worktrees
    - Return list for D-28 GitPanel display

2. Create `server/services/workspaceService.js`:

- Import `db` from `../database/db.js`
- `createWorkspace(projectId, { name, worktreeBranch })`:
  - Verify project has multi_workspace_enabled=1 (D-13)
  - If worktreeBranch: create git worktree using existing cross-spawn + git patterns from server/routes/projects.js
  - INSERT into workspaces table
  - Return created workspace
- `getWorkspaces(projectId)`:
  - Query workspaces for project
- `renameWorkspace(workspaceId, newName)`:
  - UPDATE name
- `deleteWorkspace(workspaceId, deleteWorktree)`:
  - Per D-23: if deleteWorktree=true, run `git worktree remove`
  - If deleteWorktree=false, the worktree reverts to a regular branch (visible in GitPanel)
  - DELETE from workspaces table
- `promoteWorktreeToWorkspace(projectId, worktreePath, worktreeBranch)`:
  - Per D-14b: convert an existing GitPanel worktree entry to a managed Workspace
  - INSERT into workspaces table with the worktree info

Important: All service methods use parameterized queries (db.prepare with ? placeholders) — never string concatenation for SQL.
</action>

<task type="auto">
  <name>Task 2: Create REST API routes for projects and workspaces</name>
  <files>server/routes/project-management.js</files>
  <action>
  Create `server/routes/project-management.js` with Express router:

**Project endpoints:**

- `POST /api/projects` — Create project (wizard step completion). Body: `{ name, directoryPath, multiWorkspaceEnabled }`. Validates path exists. Returns 201 with project.
- `GET /api/projects` — List projects. Query params: `sort=name|recent|created`, `includeDeleted=true|false`. Returns 200 with array.
- `GET /api/projects/:id` — Get single project with workspaces and session summary. Returns 200.
- `DELETE /api/projects/:id` — Soft-delete project (D-22). Returns 200.
- `GET /api/projects/:id/sessions` — List sessions for a project. Query params: `status=active|frozen|archived`, `q=searchTerm`, `workspaceId=N`. Returns 200 with sessions array.

**Workspace endpoints (only when multi-workspace enabled):**

- `POST /api/projects/:id/workspaces` — Create workspace. Body: `{ name, worktreeBranch }`. Returns 201.
- `GET /api/projects/:id/workspaces` — List workspaces. Returns 200.
- `PATCH /api/projects/:id/workspaces/:wsId` — Rename workspace. Body: `{ name }`. Returns 200.
- `DELETE /api/projects/:id/workspaces/:wsId` — Delete workspace. Query param: `deleteWorktree=true|false`. Returns 200. Per D-23.
- `POST /api/projects/:id/workspaces/promote` — Promote GitPanel worktree to workspace (D-14b). Body: `{ worktreePath, worktreeBranch }`. Returns 201.
- `GET /api/projects/:id/worktrees` — Detect existing worktrees in project dir (D-28). Returns 200 with array.

**Input validation:** Validate required fields, path characters (no path traversal), name length. Return 400 with error message for invalid input.

**Auth:** Use existing auth middleware from the project (same pattern as other routes).

Register this router in the server's main app setup alongside existing routes.
</action>
