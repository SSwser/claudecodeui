  1. Create `src/hooks/useSessionLifecycle.ts`:
  - `freezeSession(sessionId: string)`: POST to `/api/sessions/:id/freeze`
    - Show confirmation dialog before executing (per D-04: user must confirm freeze)
    - On success: update local state optimistically, toast "Session frozen"
  - `resumeSession(sessionId: string)`: POST to `/api/sessions/:id/resume`
    - On success: update local state, toast "Session resumed"
  - `archiveSession(sessionId: string)`: POST to `/api/sessions/:id/archive`
    - On success: toast "Session archived"
  - `deleteSession(sessionId: string)`: DELETE to `/api/sessions/:id`
    - Show confirmation dialog ("Are you sure? This cannot be undone")
    - On success: close tab if open, toast "Session deleted"
  - `getSessionState(sessionId: string)`: GET `/api/sessions/:id/state`
  - Listen for WebSocket `session_state_changed` events via existing WebSocket context:
    - Update session status across all components using the status
    - When a session transitions to frozen: disable input in that session's chat
  - Error handling: toast error message on API failure, revert optimistic update
