<task type="auto" tdd="false">
  <name>Task 1: Replace Dialog with portal-based, token-clean, accessible implementation</name>
  <files>src/components/ui/dialog.tsx</files>
  <action>
Rewrite `src/components/ui/dialog.tsx` from scratch keeping the exact same exports.
Use `ReactDOM.createPortal` to mount DialogContent into `document.body`.

**Requirements for the new implementation:**

1. **Portal mounting** — DialogContent renders via `createPortal(content, document.body)`.
   This prevents overflow:hidden and z-index issues from ancestor elements.

2. **Backdrop** — Add a `fixed inset-0 z-50 bg-black/60 backdrop-blur-sm` overlay that
   closes the dialog when clicked (unless `e.target !== backdrop`).

3. **Container** — Dialog panel should be:
   `fixed left-1/2 top-1/2 z-50 -translate-x-1/2 -translate-y-1/2 w-full max-w-lg
    rounded-lg border border-border bg-surface-elevated p-6 shadow-xl`

4. **Close button** — DialogContent includes an X button (top-right, `absolute right-4 top-4`)
   using Lucide `X` icon, calls `onOpenChange(false)`. Button: type="button".

5. **Keyboard** — On mount, add `keydown` listener for `Escape` → calls `onOpenChange(false)`.
   Remove listener on unmount.

6. **Focus management** — DialogContent sets focus to itself on open (`autoFocus` or
   `useEffect(() => ref.current?.focus(), [])`). Add `tabIndex={-1}` to dialog panel div.

7. **Animations** — Add Tailwind `animate-in fade-in-0 zoom-in-95` enter classes.
   (These are standard Tailwind animation utilities from tailwind-animate; if not available,
   use `transition-all duration-200` instead — do not add external packages.)

8. **Accessibility** — Add `role="dialog"` and `aria-modal="true"` to the panel div.
   DialogTitle must render an element that the dialog can reference via `aria-labelledby`
   (add an `id` pattern: `dialog-title-{uuid}` is optional for now, static id is acceptable).

9. **All token classes** — Use `bg-surface-elevated`, `border-border`, `text-foreground`,
   `text-muted-foreground` for all color usage. No hardcoded hex or raw gray utilities.

10. **Controlled mode** — `open` prop controls visibility. If not provided, Dialog manages
    internal state via `useState(false)`.

11. **Guard** — Keep the `typeof document === 'undefined'` guard for SSR safety.

The DialogContext approach is fine to keep — use React.createContext to share open/onOpenChange
between Dialog, DialogTrigger, and DialogContent.

Export all 7 functions (Dialog, DialogTrigger, DialogContent, DialogHeader, DialogTitle,
DialogDescription, DialogFooter) with exact same signatures as before.

<task type="auto" tdd="false">
  <name>Task 2: Replace Select with keyboard-accessible, token-clean implementation</name>
  <files>src/components/ui/select.tsx</files>
  <action>
Rewrite `src/components/ui/select.tsx` keeping the exact same exports (`SelectOption` type
and `Select` function).

**Requirements for the new implementation:**

1. **Trigger button** — Use a `<button type="button">` as the trigger (not a native `<select>`).
   Display: current selected label (or placeholder if none). Include a ChevronDown Lucide icon.
   Classes: `flex h-10 w-full items-center justify-between rounded-md border border-input
   bg-background px-3 py-2 text-sm ring-offset-background focus:outline-none focus:ring-2
   focus:ring-ring focus:ring-offset-2 disabled:cursor-not-allowed disabled:opacity-50`

2. **Dropdown panel** — Position: `absolute z-50 min-w-[8rem] rounded-md border border-border
   bg-surface-elevated p-1 shadow-md`. Use `overflow-hidden`. Mount in a wrapper with
   `relative` positioning. (Do NOT use createPortal for Select dropdown — relative portal is fine.)

3. **Option items** — Each option: `relative flex w-full cursor-default select-none items-center
   rounded-sm py-1.5 pl-8 pr-2 text-sm outline-none`. Hover: `bg-accent text-accent-foreground`.
   Selected: show a Lucide `Check` icon at `absolute left-2`. Disabled: `opacity-50 pointer-events-none`.

4. **Keyboard navigation (per D-02 — library-quality behavior):**
   - `ArrowDown` / `ArrowUp` → move focus through options (visual highlight, not actual focus)
   - `Enter` / `Space` → select highlighted option, close dropdown
   - `Escape` → close dropdown without selection
   - `Tab` → close dropdown
   Implement with `useState(highlightedIndex)` tracked in component. On open, set
   `highlightedIndex` to the index of the currently selected value.

5. **Click outside** — Add `mousedown` listener on `document` to close dropdown when clicking
   outside the component. Remove on unmount.

6. **Controlled state** — `value` + `onValueChange` is the external state. Internal state
   tracks `open` (dropdown visible) and `highlightedIndex`.

7. **Accessibility** — Add `role="combobox"` on trigger, `aria-expanded={open}`, `role="listbox"`
   on dropdown panel, `role="option"` on each item, `aria-selected={isSelected}` per item.

8. **All token classes** — Use only semantic tokens: `bg-background`, `border-input`,
   `bg-accent`, `text-accent-foreground`, `bg-surface-elevated`, `text-foreground`. No `gray-*`.

Export `SelectOption` type and `Select` function with unchanged signatures.
