## 色彩对齐策略

### Token 映射方式

| Option | Description | Selected |
|--------|-------------|----------|
| 直接替换 dark mode 变量值 | 在 .dark {} 中将 --background、--card、--border 等变量值改为 DESIGN.md 色板。组件无需改动，全局立即生效 | ✓ |
| 引入 design- 前缀新 token 层 | 保留现有 shadcn token，新增 --design-bg、--design-card 等，组件逐步切换。违反 Phase 4 D-06 决定 | |
| 按页面渐进替换 | 每个页面用 CSS scope 覆盖 token 值，页面改完后合并到全局 | |

**User's choice:** 直接替换 dark mode 变量值
**Notes:** 推荐方案——改动最小，效果最大

### Light Mode 处理

| Option | Description | Selected |
|--------|-------------|----------|
| 暂不动 light mode | DESIGN.md 只定义了 dark 主题。Light mode 保持 shadcn 默认值 | |
| 同步调整 light mode | 将 DESIGN.md dark 色板做明暗对称映射，同时更新 :root light 主题 | ✓ |

**User's choice:** 同步调整 light mode
**Notes:** 一步到位，工作量翻倍但避免后续再做一次

### 品牌色角色

| Option | Description | Selected |
|--------|-------------|----------|
| 仅用于 destructive + accent 场景 | 替换 --destructive 色值，作为 CTA、错误状态的高亮色 | |
| 引入独立 --brand 品牌 token | 新增 --brand / --brand-foreground token，与 destructive 分离 | ✓ |
| 不引入 | 保持现有蓝色系主色调，Raycast Red 不用于产品 UI | |

**User's choice:** 引入独立 --brand 品牌 token
**Notes:** 品牌色独立于错误状态，灵活度更高

## 排版系统迁移

### 字体加载策略

| Option | Description | Selected |

| Option | Description | Selected |

**User's choice:** 全局 normal=500

### Letter-spacing 应用方式

| Option | Description | Selected |
|--------|-------------|----------|
| 通过 CSS 变量全局设置 | 在 body 上设置 letter-spacing: 0.2px | |
| 通过 Tailwind class 按组件应用 | 用自定义 tracking-* class 按组件应用 | ✓ |

**User's choice:** 通过 Tailwind class 按组件应用
