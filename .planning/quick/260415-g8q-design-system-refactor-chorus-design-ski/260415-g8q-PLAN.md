## Plan 02: Migrate tokens.json to Tokens Studio Format

**Scope:** Restructure tokens.json to W3C DTCG / Tokens Studio compatible format; update build script

### Tasks

#### Task 2.1: Restructure tokens.json

- **files:** `design/tokens.json`
- **action:**
  1. Read current tokens.json (custom format with `pencilHex`, `css`, `tailwind`, `light`, `dark`)
  2. Transform each token to Tokens Studio format:
     ```json
     {
       "$value": "<pencilHex or dark HSL>",
       "$type": "color",
       "$description": "<description>",
       "$extensions": {
         "com.chorus.design": {
           "css": "<css var name>",
           "tailwind": "<tailwind class>",
           "pencilHex": "<hex>",
           "light": "<HSL values>",
           "dark": "<HSL values>"
         }
       }
     }
     ```

- **done:** tokens.json migrated to Tokens Studio format
