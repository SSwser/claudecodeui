## 核心功能（基于公开信息）

### 1. 设计到代码转换

- 上传设计图稿/截图 → AI 生成可交互原型
- 支持手绘草图转换
- 生成 HTML/CSS/JavaScript 代码

### 2. AI 驱动的原型生成

- 基于 Google Gemini 模型
- 自然语言描述 → 生成 UI 原型
- 迭代式对话优化

### 3. 交互式原型

- 生成的原型可直接交互
- 支持多页面/多场景
- 嵌入式预览

### 4. 多种输入方式

- 文字描述
- 手绘草图
- 设计截图
- 现有网页 URL

## 技术架构分析

### 技术特点

- 基于 **Google Gemini** 多模态模型
- 纯云端服务，无本地组件
- Google 基础设施支撑

### 技术限制

- **Google Labs 实验项目** — 可能随时关闭或调整方向
- 无仓库连接功能
- 不支持 Design System 集成
- 生成的代码为通用 HTML/CSS/JS，不对接特定框架
- 无 Figma 集成
- 无 API 或 MCP 支持
- 不支持组件化输出

## 与我们产品愿景的关系

### 竞争维度

| 维度              | 重叠度 | 说明                    |
| ----------------- | ------ | ----------------------- |
| AI 驱动           | 🟡 中  | AI 生成，但无仓库上下文 |
| 设计→代码         | 🟡 中  | 单向转换，不做持续同步  |
| 仓库直连          | 🟢 低  | 不连接代码仓库          |
| Design Token 同步 | 🟢 低  | 不涉及                  |
| 本地部署          | 🟢 低  | 纯云端 Google 服务      |
| Figma 集成        | 🟢 低  | 不涉及                  |

### 差异化分析

1. **Stitch 是"从零开始的AI原型工具"** — 不理解已有代码库
2. **适用于快速原型阶段** — 不适用于已有项目的设计同步
3. **无 Design System 概念** — 生成的是独立代码，不复用组件
4. **Google Labs = 不确定性高** — 可能成长为大产品，也可能被关闭

### 间接影响

- Google 进入这个领域 **验证了"AI + 设计 + 代码"的方向**
- 可能降低用户对此类工具的付费意愿（"Google 免费提供了"）
- 如果 Stitch 未来与 Flutter/Angular 深度整合 → 可能在特定生态内形成垄断
- Gemini 模型能力的提升会间接提升整个行业的 AI 设计能力

## 关键洞察

1. **Google 入局 = 市场验证** — 巨头认可"AI + 设计工具"方向
2. **但 Stitch 定位在原型阶段，不在"设计系统管理"** — 与我们差异大
3. **Google Labs 项目存活率有限** — 不应视为确定性威胁
4. **免费策略可能压低市场预期** — 用户可能期望类似功能免费
5. **技术上无重叠** — 我们关注仓库→Figma 同步，Stitch 关注创意→原型
