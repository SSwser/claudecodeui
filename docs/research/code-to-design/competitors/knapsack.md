## 核心功能

### 1. 设计系统管理

- 组件库管理和组织
- 设计系统版本控制
- 多品牌/多产品的设计系统管理
- 组件指南和文档

### 2. Figma 集成

- Figma 组件双向关联
- 设计资产同步
- Figma 文件监控

### 3. 代码集成

- 代码组件与设计组件映射
- 支持多框架组件 (React, Angular, Vue, Web Components)
- Storybook 集成
- 代码片段嵌入

### 4. 文档平台

- 自动化的设计系统文档
- 组件使用指南
- 交互式组件 playground
- Markdown 支持

### 5. 治理和发布

- 组件审批工作流
- 发布管理
- 变更追踪
- 使用分析

### 定价分析

- **无 Free / Self-service 方案** — 完全面向企业市场
- **年度计费** — 最低合同期限 1 年
- **估计**: $30K-100K+/年，基于企业 Design System 工具的一般定价
- **高准入门槛** — 需要销售流程和合同谈判

## 技术架构分析

### 特点

1. **全栈设计系统平台**: 不仅管理 token，还管理组件、文档、发布
2. **Storybook 内嵌**: 可以在平台内直接展示 Storybook stories
3. **多框架支持**: 同一组件可有 React、Angular、Vue 等多个实现
4. **治理工作流**: 审批、发布、版本控制

### 技术限制

1. **纯 SaaS** — 无本地部署选项
2. **Enterprise-only** — 中小团队无法使用
3. **不涉及 AI** — 传统工具链
4. **不做代码生成** — 主要是管理和文档，不自动生成
5. **不扫描代码仓库** — 需要手动配置组件映射
6. **代码→设计方向有限** — 主要是组织和文档化已有的 mapping

## 与我们产品愿景的关系

### 竞争维度

| 维度         | 重叠度 | 说明                       |
| ------------ | ------ | -------------------------- |
| 设计系统管理 | 🔴 高  | Knapsack 核心功能          |
| 组件映射     | 🔴 高  | 设计组件 ↔ 代码组件        |
| Figma 集成   | 🟡 中  | 有集成但不如 Supernova 深  |
| 文档生成     | 🟡 中  | 有自动化文档               |
| AI 驱动      | 🟢 低  | 无 AI                      |
| 本地部署     | 🟢 低  | 纯 SaaS                    |
| 仓库直连     | 🟡 中  | Storybook 集成需要仓库关联 |

### 差异化机会

1. **民主化**: Knapsack Enterprise-only，我们有 Free/Community 版
2. **AI 自动化**: Knapsack 手动配置，我们 AI 自动发现
3. **本地部署**: Knapsack 纯 SaaS
4. **价格亲民**: Knapsack $30K+/年，我们 $20-49/人/月
5. **代码→设计方向**: Knapsack 不做自动化的代码到设计转换

### 目标市场差异

| 维度       | Knapsack         | 我们                  |
| ---------- | ---------------- | --------------------- |
| 目标客户   | 大企业 (500+ 人) | 中小团队 → 中大型企业 |
| 定价       | $30K+/年         | $0-49/人/月           |
| 准入门槛   | 销售流程         | 自助注册              |
| 设置复杂度 | 高 (需专人配置)  | 低 (AI 自动化)        |
| AI 能力    | 无               | 核心特性              |

## 关键洞察

1. **Knapsack 验证了"Design System Platform"这个品类有商业价值** — Enterprise 愿意付高价
2. **但 Enterprise-only = 放弃了 90% 的市场** — 中小团队没有选择
3. **无 AI + 高价 + 高设置成本 = 典型的"20 世纪产品"** — 容易被颠覆
4. **Knapsack 最有价值的部分是"治理工作流"** — 审批、发布、版本控制
5. **我们可以用 AI 民主化这些 Enterprise 级功能** — 以 1/10 的价格提供 80% 的能力
6. **Storybook 集成模式可以借鉴** — 组件展示和文档化的方式
