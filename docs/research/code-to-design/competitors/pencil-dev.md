## 核心功能

### 1. 无限设计画布 (Infinite Design Canvas)

- 可视化设计工具，支持无限画布操作
- "Vibe designing with precision" — 兼顾创意自由度和精确控制

### 2. AI 多人协作 (AI Multiplayer)

- 多个 AI Agent 并行生成设计
- 类似 "并行设计员" 的工作模式

### 3. 双向 MCP 集成

- **读+写** MCP 访问 — 不同于 Figma 仅读取的 Desktop MCP
- AI 编码工具可以直接在画布上创建和修改设计
- 支持的 IDE 集成:
  - Cursor
  - VS Code
  - Claude Code
  - OpenAI Codex

### 4. 代码仓库原生

- 设计文件直接存储在代码仓库中
- 支持 Git 版本控制、分支、合并
- **开放文件格式** — 无锁定

### 5. 跨工具兼容

- 支持从 Figma 复制/粘贴
- 可使用预置设计套件或自定义套件

### 6. 代码输出

- HTML
- CSS
- React

## 技术架构分析

### 创新点

1. **设计文件即代码** — 设计文件存在仓库中，参与 Git 工作流
2. **双向 MCP** — AI 可读可写，不同于 Figma 的只读 MCP
3. **开放格式** — 无供应商锁定
4. **Agent 优先** — 为 AI agent 工作模式原生设计

### 技术限制（推断）

- 早期产品，功能成熟度待验证
- 设计套件生态系统尚未建立
- 渲染质量与 Figma 的差距未知
- 协作功能的稳定性未经大规模验证

## 与我们产品愿景的关系

### 竞争维度

| 维度               | 重叠度 | 说明                                 |
| ------------------ | ------ | ------------------------------------ |
| 仓库直连           | 🔴 高  | 核心概念相同 — 设计文件存在 Git 仓库 |
| AI 驱动            | 🔴 高  | Agent-first 设计，MCP 原生           |
| 本地部署           | 🟡 中  | 文件本地，但编辑器可能是 SaaS        |
| Design System 同步 | 🟢 低  | 未见 token 同步功能                  |

### 差异化机会

1. **Pencil 面向从零设计**，我们面向**已有代码库 → 设计同步**
2. Pencil 未涉及 **Design Token / Variables 自动同步**
3. 我们的目标包括 **Storybook 集成和组件自动化**，Pencil 侧重画布设计

### 潜在威胁

- 如果 Pencil 加入 "代码仓库扫描 → 自动生成设计" 功能，将直接竞争
- MCP 双向能力已领先 Figma，可能快速扩展功能覆盖
- 免费策略 + VC 支持 → 可能快速抢占市场

## 关键洞察

1. **Pencil 验证了"设计文件存仓库"的市场需求** — 这是我们产品愿景的核心假设之一
2. **双向 MCP 是正确方向** — Figma 只读 MCP 的限制已被竞品攻击
3. **"Agent-first"定位与我们的"仓库直连 + AI"高度重合**
4. 但 Pencil **从设计端出发**，我们可以**从代码端出发**形成差异化
